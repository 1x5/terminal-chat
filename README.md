# SecureTermChat

Защищенный P2P мессенджер с луковой маршрутизацией для командной строки.

## Текущий статус

### ✅ Реализовано:
- Базовая архитектура приложения
- Конфигурация и логирование
- Базовый UI с обработкой команд
- Заготовка для P2P сети
- Система луковой маршрутизации (базовая структура)
- Команда `/help`

### 🔄 В процессе:
- Полная реализация сетевого взаимодействия
- Доработка UI (улучшение отображения сообщений)

## Установка

```bash
# Клонируем репозиторий
git clone https://github.com/yourusername/SecureTermChat.git
cd SecureTermChat

# Создаем виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows

# Устанавливаем зависимости
pip install -r requirements.txt
```

## Использование

```bash
python src/main.py
```

### Доступные команды

- `/help` - показать справку
- `/connect <id>` - подключиться к пиру (в разработке)
- `/msg <id> <text>` - отправить сообщение (в разработке)
- `/quit` - выйти из программы
