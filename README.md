# Terminal Chat

Безопасный чат с поддержкой onion routing для терминала.

## Особенности

- 🔒 Асимметричное шифрование сообщений
- 🧅 Onion routing для анонимной коммуникации
- 🚀 Высокая производительность
- 🛡️ Защита от MITM атак
- 📝 Подробное логирование

## Статус разработки

### ✅ Реализовано
1. **Базовая криптография**
   - Генерация ключей (Ed25519)
   - Асимметричное шифрование (NaCl)
   - Создание Box для шифрования/дешифрования
   - Модульные тесты криптографических функций

2. **Onion Routing (базовая версия)**
   - Создание слоев шифрования
   - Базовая маршрутизация
   - Тесты onion routing

### 🚧 В разработке
1. **Сетевое взаимодействие**
   - Реализация протокола обмена сообщениями
   - Обработка подключений/отключений
   - Управление сетевыми соединениями

2. **Управление узлами**
   - Регистрация узлов в сети
   - Поддержание списка активных узлов
   - Обновление маршрутов

### 📋 Планируется
1. **Безопасность**
   - Проверка подлинности узлов
   - Защита от атак
   - Валидация сообщений

2. **Мониторинг и логирование**
   - Система логирования
   - Мониторинг состояния сети
   - Отслеживание ошибок

3. **Оптимизация**
   - Оптимизация маршрутизации
   - Кэширование
   - Управление ресурсами

4. **Развертывание**
   - Конфигурация
   - Скрипты развертывания
   - Обновление системы

## Установка

```bash
# Клонируем репозиторий
git clone https://github.com/1x5/terminal-chat.git
cd terminal-chat

# Устанавливаем зависимости
pip install -r requirements.txt
```

## Использование

```bash
# Запуск сервера
python src/server.py

# Запуск клиента
python src/client.py
```

## Архитектура

### Криптография
- Генерация ключей (Ed25519)
- Асимметричное шифрование (NaCl)
- Onion routing для анонимности

### Сетевое взаимодействие
- Асинхронная обработка соединений
- Маршрутизация через сеть узлов
- Обработка ошибок и восстановление

### Безопасность
- Проверка подлинности узлов
- Защита от атак
- Валидация сообщений

## Тестирование

```bash
# Запуск всех тестов
pytest

# Запуск конкретного теста
pytest tests/unit/test_crypto_keys.py -v
```
