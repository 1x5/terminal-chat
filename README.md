# SecureTermChat

Безопасный P2P чат с поддержкой луковой маршрутизации и end-to-end шифрованием.

## Особенности

- 🔒 End-to-end шифрование (X25519 + XChaCha20-Poly1305)
- 🧅 Луковая маршрутизация для анонимности
- 🔐 Аутентификация узлов
- 🛡️ Защита от DoS-атак
- 🔄 Автоматическое переподключение
- 📡 Поддержка WebSocket
- 🔑 Управление ключами
- 🧪 Unit-тесты
- 📦 Распределенная хеш-таблица (DHT)

## Требования

- Python 3.9+
- Зависимости из requirements.txt

## Установка

```bash
pip install -r requirements.txt
```

## Использование

```python
from src.network import P2PNetwork
from src.crypto import CryptoManager
from src.security import SecurityManager
from src.dht import DHT

# Инициализация
crypto = CryptoManager()
security = SecurityManager(crypto)
dht = DHT(node_id="your_node_id")
network = P2PNetwork(config, crypto)

# Подключение к сети
await network.start()

# Хранение данных в DHT
await dht.store("key", "value", replicas=3, ttl=3600)

# Получение данных из DHT
value = await dht.get("key")

# Отправка сообщения
await network.send_message(peer_address, message)

# Остановка
await network.stop()
```

## Архитектура

### Криптография
- Генерация ключей (Ed25519)
- Асимметричное шифрование (NaCl)
- Onion routing для анонимности

### Сетевое взаимодействие
- Асинхронная обработка соединений
- Маршрутизация через сеть узлов
- Обработка ошибок и восстановление
- DHT для распределенного хранения

### Безопасность
- Проверка подлинности узлов
- Защита от атак
- Валидация сообщений
