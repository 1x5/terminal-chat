# SecureTermChat

Защищенный P2P мессенджер с end-to-end шифрованием для командной строки.

## Возможности

- P2P архитектура без центрального сервера
- End-to-end шифрование сообщений
- Система репутации пиров
- Простой консольный интерфейс
- Поддержка нескольких одновременных соединений

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/1x5/terminal-chat.git
cd terminal-chat
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Использование

1. Запустите приложение:
```bash
python3 src/main.py
```

2. Для запуска второго экземпляра на другом порту:
```bash
python3 src/main.py --port 8766
```

### Основные команды

- `/add <адрес>:<порт>` - Добавить новый контакт
- `/подключить <адрес> <порт>` - Подключиться к пиру
- `/отключить` - Отключиться от текущего чата
- `/контакты` - Показать список контактов
- `/статус` - Показать статус сети
- `/очистить` - Очистить историю чата
- `/выход` - Выйти из приложения
- `/помощь` - Показать список команд
