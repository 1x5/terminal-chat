# SecureTermChat

Защищенный P2P мессенджер с луковой маршрутизацией для командной строки.

## Возможности

- P2P архитектура без центрального сервера
- Луковая маршрутизация для анонимности
- Шифрование сообщений
- Консольный интерфейс
- Защита от Sybil-атак
- Система репутации пиров

## Установка

```bash
# Клонируем репозиторий
git clone https://github.com/yourusername/SecureTermChat.git
cd SecureTermChat

# Создаем виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows

# Устанавливаем зависимости
pip install -r requirements.txt
```

## Использование

```bash
python src/main.py
```

### Команды

- `/help` - показать справку
- `/connect <id>` - подключиться к пиру
- `/msg <id> <text>` - отправить сообщение
- `/quit` - выйти из программы

## Безопасность

- End-to-end шифрование
- Луковая маршрутизация
