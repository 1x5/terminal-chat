# Руководство по быстрому запуску SecureTermChat

## Требования

- Python 3.7 или выше
- pip (для установки зависимостей)
- Поддерживаемые операционные системы: Linux, macOS, Windows

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/username/securetermchat.git
cd securetermchat
```

### 2. Создание виртуального окружения (рекомендуется)

```bash
# Linux/macOS
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Установка приложения в режиме разработки

```bash
pip install -e .
```

## Запуск

### Запуск из командной строки

```bash
# Если установлен через pip
securetermchat

# Или напрямую через Python
python securetermchat.py
```

### Параметры командной строки

- `--config <путь>` - Указать путь к файлу конфигурации
- `--debug` - Включить режим отладки (подробное логирование)

### Пример запуска с параметрами

```bash
securetermchat --debug --config my_config.json
```

## Базовые команды

После запуска приложения вы можете использовать следующие команды:

- `/help` - Показать справку
- `/exit` - Выйти из приложения
- `/add <имя> <ключ>` - Добавить новый контакт
- `/contacts` - Показать список контактов
- `/connect <имя>` - Начать чат с контактом
- `/disconnect` - Закрыть текущий чат
- `/status` - Показать статус сети

## Настройка

### Файл конфигурации

По умолчанию приложение создаёт файл конфигурации в `~/.securetermchat/config.json`. Вы можете изменить значения в этом файле или указать свой путь с помощью параметра `--config`.

### Пример файла конфигурации

```json
{
  "node_id": "auto-generated",
  "listen_host": "0.0.0.0",
  "listen_port": 8765,
  "bootstrap_nodes": [
    "seed1.securetermchat.example:8765",
    "seed2.securetermchat.example:8765"
  ],
  "min_hops": 3,
  "max_hops": 5,
  "circuit_max_age": 3600,
  "circuit_idle_timeout": 600,
  "log_level": "INFO"
}
```

## Устранение неполадок

### Проблемы с сетью

Если у вас возникают проблемы с подключением к сети:

1. Проверьте, что порт, указанный в конфигурации, не заблокирован брандмауэром
2. Если вы находитесь за NAT, настройте проброс портов на вашем роутере
3. Попробуйте подключиться напрямую к известному узлу с помощью команды `/connect_node <host:port>`

### Логи

Приложение создаёт лог-файл `securetermchat.log` в текущей директории. Проверьте его содержимое для диагностики проблем. В режиме отладки (`--debug`) логи будут более подробными.

### Сброс настроек

Если вы хотите сбросить все настройки и начать заново:

1. Остановите приложение
2. Удалите директорию `~/.securetermchat/`
3. Запустите приложение снова

## Безопасность

При обмене ключами с контактами:

1. Используйте безопасные каналы связи для обмена ключами
2. Всегда проверяйте отпечатки ключей для подтверждения личности
3. Не передавайте свой приватный ключ никому
